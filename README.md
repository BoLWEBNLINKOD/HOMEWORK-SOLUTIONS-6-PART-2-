# HOMEWORK-SOLUTIONS-6-PART-2-

Command
Это интерфейс для всех "команд". Он определяет 2 метода: execute() для выполнения действия и undo() для его отмены. Такой подход позволяет отделить клиента (пульт) от конкретной логики работы устройства. Всё, что нужно знать клиенту — что у команды есть execute() и undo(), а что именно внутри, его не волнует.

Light
Это "приёмник" команды — умная лампочка. У неё есть метод turnOn() (включить свет) и turnOff() (выключить свет). При включении выводит:
[Light] Turning ON.
При выключении:
[Light] Turning OFF.
Команды будут вызывать эти методы внутри своих execute() и undo().

Thermostat
Это второй "приёмник" команды — термостат для умного дома. Метод setTemperature() устанавливает новую температуру и запоминает старую для отката, выводя:
[Thermostat] Setting temperature to 22°C.
Метод revertTemperature() возвращает предыдущее значение и выводит сообщение с предыдущей температурой.

TurnOnLightCommand
Это конкретная команда для лампы. В методе execute() она вызывает turnOn() на объекте Light. В undo() — turnOff(). Например, при нажатии на кнопку команда включит свет и выведет:
[Light] Turning ON.
А если нажать "undo" — свет выключится и будет выведено:
[Light] Turning OFF.

SetThermostatCommand
Это команда для установки температуры у термостата. В конструктор передаётся нужное значение температуры и объект Thermostat. В execute() термостату присваивается новое значение и выводится:
[Thermostat] Setting temperature to XX°C.
В undo() температура возвращается к предыдущему значению с сообщением:
[Thermostat] Reverting to previous temperature: XX°C.

MacroCommand
Это бонусная команда-композит: она позволяет сгруппировать несколько команд в одну, например "Goodnight Mode" (выключить свет, снизить температуру). При execute() выполняются все команды по порядку, а при undo() — в обратном порядке. Это позволяет отменить сразу несколько действий одним нажатием.

SmartHomeRemoteControl
Это "Invoker" — пульт управления умным домом. Здесь хранятся назначенные команды в Map<String, Command> и история выполненных команд в Stack для поддержки undo.
Метод pressButton() выполняет команду по имени слота и запоминает её в истории.
Метод undoButton() берёт последнюю команду из истории и вызывает у неё undo().
К примеру что выведет код: 
[Light] Turning ON
[Thermostat] Setting temperature to 22°C
[Remote] Undoing last command...
[Thermostat] Reverting to previous temperature: 20°C
