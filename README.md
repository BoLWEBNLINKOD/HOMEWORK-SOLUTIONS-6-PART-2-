# HOMEWORK-SOLUTIONS-6-PART-2-

Command
Это интерфейс для всех "команд". Он определяет 2 метода: execute() для выполнения действия и undo() для его отмены. Такой подход позволяет отделить клиента (пульт) от конкретной логики работы устройства. Всё, что нужно знать клиенту — что у команды есть execute() и undo(), а что именно внутри, его не волнует.

Light
Это "приёмник" команды — умная лампочка. У неё есть метод turnOn() (включить свет) и turnOff() (выключить свет). При включении выводит:
[Light] Turning ON.
При выключении:
[Light] Turning OFF.
Команды будут вызывать эти методы внутри своих execute() и undo().

Thermostat
Это второй "приёмник" команды — термостат для умного дома. Метод setTemperature() устанавливает новую температуру и запоминает старую для отката, выводя:
[Thermostat] Setting temperature to 22°C.
Метод revertTemperature() возвращает предыдущее значение и выводит сообщение с предыдущей температурой.

TurnOnLightCommand
Это конкретная команда для лампы. В методе execute() она вызывает turnOn() на объекте Light. В undo() — turnOff(). Например, при нажатии на кнопку команда включит свет и выведет:
[Light] Turning ON.
А если нажать "undo" — свет выключится и будет выведено:
[Light] Turning OFF.
